# Архитектура и границы текущего прототипа

Читайте вместе с `README.md`, `PROJECT_STATE.md` и `ROADMAP.md`. Этот документ описывает фактическую реализацию, не обещает невыполненные требования.

Пользовательский интерфейс: React, TypeScript, TanStack Router/Start. Сервер: Node.js/Nitro. В `src/lib/api.server.ts` реализованы REST-маршруты, общая авторизация сотрудника по cookie и отдельный серверный токен интеграции. `src/lib/store.server.ts` использует SQLite на постоянном диске и хранит карточки, изменения, взаимодействия и предложения обновления. `src/lib/scoring.ts` рассчитывает оценку пригодности; она не является независимой проверкой финансовой устойчивости или надёжности контрагента. `src/lib/supplier-search.ts` ранжирует текстовый поиск; `src/lib/recommend.ts` выбирает до трёх кандидатов, исключая текущих партнёров и чёрный список.

При развёртывании на alwaysdata код находится отдельно от SQLite-файла. Пакет собирается из `.output` и адаптера запуска в `deploy/alwaysdata/`; база, секреты и архивы резервных копий в Git и сборку не входят. Бесплатный тариф позволяет показать процесс, но не обеспечивает обещаний коммерческого уровня доступности. 24.10.2026 наблюдались ответы длительностью до 57 секунд; причина не доказана. Клиент должен явно показывать ошибку и повтор, а не трактовать её как пустой каталог.

Модель `Supplier` содержит текстовый список сведений о документах (`documents: string[]`). **Никакого файлового upload, хранения КП, соглашений или сертификатов в этом прототипе нет.** Для MVP граница расширяется отдельным хранилищем файлов, правами, проверкой и аудитом; подробности в `ROADMAP.md`.

Известный долг: отдельные пользователи/роли, live discovery, бесплатная внешняя LLM с подтверждёнными условиями, наблюдаемость и полная сквозная приёмка. Не подменяйте эти границы заглушками, выдаваемыми за готовую функцию.
