# Сообщение HR — черновик для отправки владельцем

**Тема:** Тестовое задание — «Поставка», сервис поиска и сравнения поставщиков

Здравствуйте!

Направляю результат тестового задания: «Поставка» — прототип сервиса, который помогает закупщику найти поставщиков food-направления, сравнить доступные сведения и решить, с кем связаться в первую очередь.

- **Прототип:** https://demonstration.alwaysdata.net/
- **Репозиторий и README:** https://github.com/svobodastalkera1-rgb/postavka
- **Самостоятельная оценка решения:** https://github.com/svobodastalkera1-rgb/postavka/blob/main/docs/product/REVIEWER_GUIDE.md
- **План развития:** https://github.com/svobodastalkera1-rgb/postavka/blob/main/ROADMAP.md

На стенде можно без регистрации пройти основной сценарий: отфильтровать компании по категории и географии, открыть карточку с источниками и контактами, сравнить кандидатов и увидеть, почему один из них больше подходит для первого контакта. В базе 32 реальные организации. Неизвестные цены и условия оставлены пустыми, поскольку решение о закупке требует проверенных данных, а не догадок.

Отдельное внимание я уделил работе после первого поиска. Карточка хранит коммерческие условия, результаты общения, статусы и историю изменений: следующий сотрудник может продолжить переговоры, не восстанавливая их ход по переписке. Поиск сейчас работает по сохранённому каталогу; живой поиск в интернете и AI не выдаются за готовые функции. Веб-поиск в любом случае охватывает только опубликованные сведения, поэтому предусмотрено ручное добавление компании и проверка данных человеком.

Разработку можно передать другому инженеру или AI-агенту: в репозитории есть актуальное состояние, очередь проверяемых задач, архитектурные решения, проверки и правила передачи работы. Это позволяет продолжать проект без зависимости от одного чата или устройства, сохраняя контроль владельца над продуктовыми решениями.

В README и руководстве для проверяющих описаны логика сервиса, соответствие пунктам задания, ограничения демо и причины выбранного подхода. Буду рад обсудить решения и следующие шаги.
