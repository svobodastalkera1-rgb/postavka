# Скриншоты прототипа

Здесь хранятся изображения для раздела «Скриншоты» в корневом README. Используйте имена из таблицы в нём: `catalog.PNG`, `organization.PNG`, `summary.PNG`, `edited.PNG`, `dashdoard.PNG`.

1. Откройте демо на экране шириной около 1440 пикселей и подготовьте понятное состояние каждого раздела. Для сравнения выберите две компании одной товарной категории.
2. Снимайте содержимое приложения без вкладок и адресной строки браузера. Сохраняйте изображения в WebP или PNG, старайтесь не делать файлы излишне большими.
3. Перед публикацией проверьте каждый кадр: на нём не должно быть паролей, токенов, личных контактов, внутренних заметок и конфиденциальных коммерческих условий. Для редактора и истории используйте демонстрационные данные.
4. В GitHub переключитесь на ветку открытого PR, откройте эту папку и выберите **Add file → Upload files**. Перетащите изображения, затем создайте коммит в той же ветке.
5. Отредактируйте корневой `README.md`: под заголовком «Скриншоты» добавьте ссылки на загруженные изображения и сохраните ещё один коммит. GitHub покажет изображения прямо на странице README и обновит PR.

Пример для корневого README:

```markdown
![Каталог: отбор по категории и региону](docs/screenshots/catalog.PNG)

![Карточка поставщика: сведения и источники](docs/screenshots/organization.PNG)
```

Путь указывается относительно корня репозитория, регистр букв в имени файла должен совпадать. После загрузки откройте страницу README на GitHub и проверьте, что все изображения отображаются. Не добавляйте ссылки на файлы до их загрузки, иначе вместо галереи появятся битые изображения.
