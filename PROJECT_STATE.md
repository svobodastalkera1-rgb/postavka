## Проверенный функционал

Каталог содержит 32 сохранённые организации с открытыми источниками. Есть просмотр, ручное создание и редактирование карточек, коммерческих условий, контактов, внутренних заметок, статусов, подтверждений и истории. Контакты — отдельные карточки. Сводка «Данные» показывает информацию из специальных разделов. Поиск каталога учитывает телефон и контактных лиц; подбор «Мне повезёт!» исключает действующих партнёров и чёрный список. Скоринг пересчитывается после изменения значимых полей, при этом достоверность данных и пригодность поставщика различаются. REST API и OpenAPI доступны, а приватные поля скрываются от гостя. SQLite хранится на постоянном диске вне каталога приложения, резервная копия была проверена при предыдущем обновлении.

Коммит `5b9dd2d3a1aa9e9cbf9a4e591df41b75046dabaf` в PR #7 включает сообщения о сбоях API, поиск по телефону в «Мне повезёт!» и отдельные поля вместо ввода массивов и цен через `|`. GitHub Frontend checks прошли. Перед развёртыванием создана проверенная резервная копия SQLite; предыдущая сборка сохранена для отката. После перезапуска вручную проверены обзор, каталог с 32 компаниями, аналитика, OpenAPI, поиск по телефону и сравнение двух компаний. Владелец 24.10.2026 сообщил об успешном входе под новым паролем и повторном редактировании карточек на опубликованном стенде.

## Открытые ограничения и риски

- Живой интернет-поиск и внешняя LLM пока не реализованы и не подтверждены бесплатной эксплуатацией. AI-страница не должна рекламироваться как работающий AI.
- Отдельные учётные записи сотрудников и полноценное управление ролями отсутствуют; используется общий пароль редактора. Интеграционный токен задаётся сервером, UI управления им нет.
- Загрузка файлов документов, КП и соглашений в прототипе и на демо-стенде не реализуется. Можно хранить только текстовые сведения о документах. Файловое хранилище запланировано для MVP.
- 24.10 HTTP-журнал alwaysdata показал ответы длительностью до 57 секунд; позже сервис восстановился и вернул все 32 записи. Первопричина задержки не установлена. Обновлённый UI показывает ошибку вместо ложных нулей при сбое API; это не устраняет серверную задержку.
- 24.10 владелец сообщил, что заменил шаблонные значения пароля редактора и ключа сессии в панели. Не проверять и не записывать значения в репозиторий; после смены ключа пользователям потребуется повторный вход.
- Нет доказательств готовности к коммерческой эксплуатации, интеграции с конкретной 1С, работы AI или десяти сквозных приёмочных сценариев внутренних дополнений. Репозиторий остаётся приватным. Исходное задание работодателя сверено отдельно в `docs/product/REVIEWER_GUIDE.md`.
